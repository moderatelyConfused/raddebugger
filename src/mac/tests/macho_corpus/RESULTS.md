### Row attribution at inline-site boundaries

Rows are no longer merged when decoded (bug 12), so a row beginning at a site's boundary belongs to that site, and the "run past" rule gives the code a row covers after its site ended the call line of the site (Rust `dealloc`: `[0x25800, 0x25804)` carries `deallocate`'s call line 725 in `shrink_unchecked`'s table). What remains is what the DWARF says: code the line program attributes to an inlinee's line *before* the site begins, or in a row of its own after it ended, stays in the enclosing table with that line. A rule splitting rows carrying a different file than the enclosing frame's would not catch the Rust case (both lines are in `alloc.rs`) and would need the inlinee's file for every site (its abstract origin's `DW_AT_decl_file`), while the line program's attribution is deliberate (LLVM's `prologue_end` / scheduled instructions); it is not implemented.

### Remaining failures and known limits

* None in the table (74 of 74).
* Qualified names: an anonymous namespace or class contributes an empty part (`main::::operator()` for a lambda's call operator: `main` → the unnamed closure class → `operator()`), where lldb prints `(anonymous namespace)` / `(anonymous class)`; the join lives in `fully_qualified_from_rdi_string_and_container` (`src/rdi/rdi_local.c`). Zig's names are already paths (`Target.Cpu.Model`), and a type nested in a type gets both: `Target.Os::Target.Os.WindowsVersion.Range` (the checker expects the same).
* Inline sites keep the inlinee's bare name (`area`): the frame display reads `RDI_InlineSite.name_string_idx` directly, and `RDIM_InlineSite.owner` is not set.
* The `[symbol table only]` producer marker is written; the debugger's staleness check (`dbg_info.c`, "determine if RDI is stale") does not yet re-convert such an RDI once a dSYM or the debug map's objects are available.
* Not checked: locals (locations, types), type byte sizes, unwind info, the x86_64 slice of the universal binary (`--arch x86_64` compares against that slice, but radbin converts the arm64 one).
